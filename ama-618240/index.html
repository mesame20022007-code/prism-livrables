Temps de jeu par jour

Android : Paramètres → Sécurité (ou Écran de verrouillage) → Épinglage d'écran, active-le. Ouvre le livre, appuie sur le bouton « Aperçu » (carré), touche l'icône du livre en haut, puis Épingler. Pour sortir : maintiens « Retour » et « Aperçu » ensemble.

iPhone / iPad : Réglages → Accessibilité → Accès guidé, active-le. Ouvre le livre et appuie 3 fois sur le bouton latéral.

Les noms des menus changent un peu selon la marque du téléphone. Ce réglage est la seule façon sûre d'empêcher de quitter l'appli : le code parent bloque les menus du livre, mais pas les boutons du téléphone.
