📘 Guide en images (comment tout faire)
Android : Paramètres → Sécurité (ou Écran de verrouillage) → Épinglage d'écran, activez-le. Ouvrez le livre, appuyez sur le bouton « Aperçu » (carré), touchez l'icône du livre en haut, puis Épingler. Pour sortir : maintenez « Retour » et « Aperçu » ensemble.

iPhone / iPad : Réglages → Accessibilité → Accès guidé, activez-le. Ouvrez le livre et appuyez 3 fois sur le bouton latéral.

Les noms des menus changent un peu selon la marque du téléphone. Ce réglage est la seule façon sûre d'empêcher de quitter l'appli : le code parent bloque les menus du livre, mais pas les boutons du téléphone.
